# DARK STAR CULINARY

Production public website repository for **Dark Star Culinary** — an elite, private culinary and bespoke dining operation within the Dark Star Ecosystem.

## Features
- **Cinematic Entrance & Identity Reveal**: Ambient ember particles, gold typography, dark luxury visual language.
- **Editorial About & Philosophy**: Dedicated story, culinary approach, and hospitality ethos.
- **Bespoke Portfolio Gallery**: Dynamic category filtering (Plated, Events, Atmosphere, Detail) with expandable lightbox view.
- **Substantial Private Events Intake**: Multi-step booking inquiry flow with detailed preference capture, guest counts, dietary notes, and explicit inquiry status guarantees.
- **Responsive & Accessible**: Optimized for mobile, desktop, keyboard navigation, and `prefers-reduced-motion`.

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

Deployed via Netlify.
